# JuniorJol для работодателей

JuniorJol — открытый список стажировок и junior-вакансий в IT Казахстана. Его читают студенты и выпускники IT-специальностей: через GitHub, Telegram-канал, сайт и RSS.

**Почему у нас:**

- **Целевая аудитория.** Только начинающие специалисты: ваша стажировка не теряется среди вакансий для senior'ов.
- **Свежесть.** Каждая вакансия проверена модератором, просроченные снимаются автоматически — студенты доверяют списку.
- **Бесплатное базовое размещение.** Платите, только если нужно больше охвата.
- **Прозрачность.** Все правила и данные открыты, никаких скрытых списаний.

## Как разместить

1. Заполните [форму «Новая вакансия»](../../../issues/new?template=new-listing.yml) (нужен бесплатный аккаунт GitHub).
2. Бот сразу проверит заявку и покажет превью. Если что-то не так — поправьте описание issue, бот перепроверит.
3. Модератор опубликует вакансию в течение 1–2 рабочих дней.
4. Когда набор закроется — заполните [форму «Закрыть вакансию»](../../../issues/new?template=close-listing.yml) или напишите в своей заявке.

Нет аккаунта GitHub? Регистрация занимает минуту, а можно попросить коллегу-разработчика: аккаунт есть почти у каждого. Или напишите нам через Telegram-канал (ссылка в README) — разместим за вас.

## Оплата

- Оплата через **Kaspi Pay** по ссылке — бот пришлёт её в вашей заявке. В сообщении к платежу укажите номер заявки (например, `JuniorJol #12`).
- Для ТОО и ИП — счёт на оплату и закрывающие документы по запросу.
- Продвижение включается в течение рабочего дня после оплаты. Если вакансию не удалось опубликовать по нашей вине — вернём деньги.

## Правила

Мы **не** публикуем:

- вакансии без ссылки на официальный источник (сайт компании, hh.kz, LinkedIn, форма отклика);
- требования к полу, возрасту, внешности, национальности и другие дискриминационные условия;
- «стажировки», за участие в которых платит сам стажёр, курсы под видом работы, MLM;
- вакансии с личными телефонами в тексте — только рабочие каналы связи.

Модератор вправе отклонить заявку с объяснением причины. Платные услуги не обходят модерацию.
