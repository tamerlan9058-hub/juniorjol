# Бизнес-модель JuniorJol

> **В одной фразе:** открытая доска стажировок и junior-вакансий в IT Казахстана, которая целиком работает на GitHub. Для студентов она бесплатна, а деньги платят работодатели за продвижение и спонсоры за доступ к аудитории.

## 1. Почему не «платный датасет через GitHub Sponsors»

Первым рассматривался вариант с платным «живым» датасетом в приватном репозитории, доступ к которому продаётся через GitHub Sponsors. Идея использовать GitHub как всю инфраструктуру (Actions, Issue Forms, Pages) хорошая, и она здесь сохранена. Но в роли основной бизнес-модели этот вариант не подходит основателю-студенту из Казахстана:

| Проблема | Почему важно |
|---|---|
| **Касса недоступна.** Казахстана нет в найденных списках регионов GitHub Sponsors, а Stripe, через который идут выплаты, в Казахстане не работает. Для таких стран есть только лист ожидания. ([GitHub Docs](https://docs.github.com/en/sponsors/getting-started-with-github-sponsors/about-github-sponsors), [обсуждение листа ожидания](https://github.com/orgs/community/discussions/82398)) | Основной способ оплаты может так и не заработать. |
| **Платные данные покупает B2B.** Продажа датасетов требует отраслевой экспертизы и долгих продаж компаниям. | У студента первого курса этого пока нет. |
| **Чужие источники.** Сбор данных с госзакупок, hh.kz и т. п. упирается в их правила использования. | Юридический риск возникает с первого дня. |
| **Приватный репозиторий легко «утекает».** Любой подписчик может скопировать данные и раздать их. | Продукт трудно защитить. |

Здесь всё наоборот. Деньги принимаются через **Kaspi Pay**, который есть у любого ИП в Казахстане. Данные присылают сами работодатели, поэтому споров о лицензиях нет. Ценность проекта не в секретности, а в **аудитории и доверии**, которые нельзя скопировать вместе с JSON.

## 2. Проблема и подтверждение спроса

- **Студенты** узнают о стажировках случайно: из чатов, сторис и от знакомых. Набор на многие программы короткий, и его легко пропустить.
- **Работодатели** публикуют стажировки на общих job-сайтах, где они теряются среди вакансий для опытных специалистов. Кроме того, там приходится платить за каждую публикацию: в 2023 году на hh.kz стоили «Стандарт» 4 600 ₸, «Стандарт плюс» 14 000 ₸ и «Премиум» 20 000 ₸ ([hh.kz](https://hh.kz/article/31019)).
- **Спрос уже подтверждён.** Репозиторий [danabeknar/kazakhstan-it-internships](https://github.com/danabeknar/kazakhstan-it-internships) со списком IT-стажировок в Казахстане набрал **600+ звёзд**. Но список ведётся вручную через правки README, у многих записей нет дедлайнов или они относятся к 2021–2023 годам, а монетизации нет. Людям это нужно, но нужно свежим.

## 3. Решение

| Для кого | Что получает | Цена |
|---|---|---|
| Студенты и выпускники | Свежий проверенный список со ссылками на официальные источники, дедлайнами, Telegram, RSS и сайтом с фильтрами | Бесплатно всегда |
| Работодатели | Бесплатное размещение для целевой junior-аудитории и платное продвижение | 0 ₸ / от 9 900 ₸ |
| Школы программирования, вузы, IT-сервисы | Спонсорская строка в шапке, упоминания в дайджестах | 49 900 ₸/мес |
| Разработчики | Открытый JSON/RSS для своих ботов | Бесплатно (CC BY 4.0) |

**Чем отличаемся от конкурентов** (hh.kz, Telegram-каналы с вакансиями, ручные списки):

1. Только junior и стажировки, а не «всё подряд».
2. Свежесть: у каждой вакансии есть срок, просроченные снимаются автоматически каждое утро.
3. Модерация: ссылка только на официальный источник, фильтр дискриминационных требований, отказ «стажировкам», за которые платит сам стажёр.
4. Открытые данные и прозрачные правила вызывают доверие у студентов и у вузов.

## 4. Как это работает технически

Свои сервер, база данных и хостинг не нужны:

- **Issue Forms** принимают заявки работодателей.
- **GitHub Actions** проверяют заявку (бот сразу отвечает в issue), после метки модератора публикуют вакансию, каждое утро снимают просроченные и раз в неделю отправляют дайджест в Telegram.
- Основная витрина — **README**, он перегенерируется автоматически. Кроме него есть **GitHub Pages** (сайт с фильтрами), **RSS** и **JSON**.
- **Telegram-канал** — главный канал доставки: студенты живут там, а не на GitHub.

Для публичных репозиториев Actions бесплатны, Telegram бесплатен. Деньги нужны только на ИП, когда появятся платящие клиенты (см. раздел 6).

## 5. Монетизация

| Продукт | Что входит | Цена | Кто покупает |
|---|---|---|---|
| Featured | ⭐ вверху списка на 30 дней, закреп в Telegram на 3 дня, повтор в дайджесте | 9 900 ₸ | HR компаний с потоком стажёров |
| Пакет «Набор стажёров» | 3 Featured + отдельный пост о программе | 24 900 ₸ | Компании с весенним/осенним набором |
| Спонсор месяца | Строка в шапке README и сайта + упоминание в каждом дайджесте | 49 900 ₸/мес | Школы программирования, курсы английского для IT, сервисы для студентов |
| *Позже:* «Найм под ключ» | Отбор и предварительный скрининг кандидатов на стажировку | от 100 000 ₸ | Небольшие компании без HR |

Цена Featured находится между «Стандартом» и «Премиумом» hh.kz, но охват при этом целевой. Цены задаются в `config.json` и сами подставляются в [тарифы](employers.md) и в ответы бота.

## 6. Расходы и юнит-экономика

**Расходы (2026):**

- GitHub, Actions, Pages, Telegram — 0 ₸.
- ИП на упрощённой декларации: налог **4 %** от дохода ([mybuh.kz](https://mybuh.kz/news/uproshchenka-2026-chto-menyaetsya/)). Платежи за себя — минимум около **21 675 ₸/мес** с 1 МЗП ([calk.kz](https://calk.kz/calculator/ip-payments/)).
- Комиссия Kaspi Pay — в расчёте заложено **2 %** (это допущение, проверь тариф при подключении).
- Время: модерация около 10 минут на вакансию, продажи и партнёрства — 5–10 часов в месяц.

**Точка безубыточности:** чистыми с одного Featured остаётся 9 900 × 0,94 ≈ 9 300 ₸. Значит, **3 Featured в месяц** покрывают платежи ИП. До этого момента ИП **не регистрируем**: сначала бесплатная фаза и проверка спроса.

**Сценарии на 12-й месяц** (выручка в месяц, это гипотезы для проверки):

| | Пессимистичный | Базовый | Оптимистичный |
|---|---|---|---|
| Featured | 2 × 9 900 | 6 × 9 900 | 15 × 9 900 |
| Пакеты | — | 1 × 24 900 | 3 × 24 900 |
| Спонсоры | — | 1 × 49 900 | 2 × 49 900 |
| **Выручка** | **19 800 ₸** | **134 200 ₸** | **323 000 ₸** |
| Налог 4 % + Kaspi 2 % | 1 188 ₸ | 8 052 ₸ | 19 380 ₸ |
| Платежи ИП | 21 675 ₸ | 21 675 ₸ | 21 675 ₸ |
| **Чистыми** | **−3 063 ₸** → ИП не открываем, остаёмся бесплатным проектом для портфолио | **104 473 ₸** | **281 945 ₸** |

Допущения базового сценария: около 60 новых вакансий в месяц, 8–10 % из них работодатели продвигают, в Telegram-канале 3 000+ подписчиков (с этого уровня реально продавать спонсорство).

## 7. Business Model Canvas

| Блок | Содержание |
|---|---|
| Клиентские сегменты | Студенты и выпускники IT (пользователи); HR IT-компаний и банков (платят); школы программирования и сервисы для студентов (спонсоры); карьерные центры вузов (партнёры) |
| Ценность | Студентам — свежие стажировки в одном месте; работодателям — целевая аудитория бесплатно или дёшево; спонсорам — доступ к студентам IT |
| Каналы | Telegram-канал, README на GitHub, сайт на Pages, чаты вузов, LinkedIn |
| Отношения | Самообслуживание через формы и бот, модерация, ответы в issue |
| Доходы | Featured, пакеты, спонсорство; позже — «найм под ключ» |
| Ключевые ресурсы | Аудитория, доверие, автоматизация в репозитории |
| Ключевые действия | Модерация, наполнение на старте, привлечение работодателей и партнёров |
| Партнёры | Карьерные центры вузов, студенческие IT-клубы, Astana Hub, авторы похожих списков (в первую очередь danabeknar/kazakhstan-it-internships) |
| Расходы | Время основателя; ИП и налоги после выхода на доход |

## 8. План запуска

| Срок | Что делаем | Цель (метрика) |
|---|---|---|
| **День 0** | Сделать репозиторий публичным, пройти [чек-лист запуска](setup.md) | Бот отвечает на тестовую заявку |
| **Недели 1–2: холодный старт** | Самому завести 30–50 актуальных стажировок и junior-вакансий из открытых карьерных страниц компаний (через формы, чтобы проверить весь процесс). Написать автору danabeknar/kazakhstan-it-internships и предложить объединиться или обменяться ссылками | 40+ активных вакансий |
| **Месяц 1** | Посты в чатах своего вуза и соседних (Polytech, KBTU, SDU, AITU, IITU, NU), в студенческих IT-клубах. Письма 50 HR в LinkedIn: «разместим бесплатно, Featured тоже бесплатно — это запуск» | 500 подписчиков в Telegram, 10 работодателей размещают вакансии сами |
| **Месяц 2–3: первые деньги** | Когда минимум 3 работодателя готовы платить, открыть ИП через eGov, подключить Kaspi Pay, выключить `launch_promo` в config.json | 3 платных Featured в месяц (безубыточность) |
| **Месяцы 4–6** | Продать первое спонсорство школе программирования. Подготовиться к весеннему сезону стажировок (февраль–апрель): «Пакет «Набор стажёров» | 1 спонсор, 1 500 подписчиков |
| **Месяцы 6–12** | Казахская версия сайта и постов, партнёрства с карьерными центрами вузов (они получают готовую ленту вакансий), пилот «Найм под ключ» | Базовый сценарий: ~130 000 ₸/мес выручки |

## 9. Метрики

- **Главная метрика:** число активных вакансий. Без вакансий нет ни студентов, ни денег.
- Новые вакансии в неделю и доля, которую работодатели разместили сами (а не модератор).
- Подписчики Telegram и звёзды репозитория — размер аудитории для спонсоров.
- Конверсия в Featured и выручка в месяц.
- Время модерации: заявка не должна ждать дольше 2 рабочих дней.

## 10. Риски и что с ними делаем

| Риск | Что делаем |
|---|---|
| Холодный старт: нет вакансий → нет студентов → нет работодателей | Первые 40 вакансий заводим сами, Featured бесплатно на запуске, партнёрства с вузами |
| Вход дешёвый — могут скопировать | Защищает не код (он открыт), а аудитория, доверие и отношения с HR. Скорость важнее секретности |
| Фейковые вакансии и мошенничество («работа для студентов») | Ручная модерация, только официальные ссылки, форма жалобы, отказ платным «стажировкам» |
| Сезонность: летом и в декабре заявок меньше | Спонсорство и дайджесты в низкий сезон, акцент на весенний и осенний наборы |
| Работодателям непривычен GitHub | Модератор размещает вакансию за них по письму или сообщению в Telegram; в планах форма на сайте |
| Ограничения GitHub. Pages нельзя использовать как хостинг интернет-магазина или SaaS ([GitHub Docs](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)) | Сайт — бесплатная информационная витрина, оплата проходит вне GitHub. Если возникнут вопросы, сайт за час переносится на любой бесплатный статический хостинг, README остаётся |
| Запуски по расписанию в публичном репозитории выключаются после 60 дней без активности | При регулярных заявках этого не будет. Если выключились — включить в Actions одной кнопкой |
| Законы РК: запрет дискриминации при найме, персональные данные, налоги | Фильтр дискриминационных требований в боте; данные студентов не собираем; ИП на упрощёнке — только с первыми платящими клиентами |
| Выгорание основателя-студента | Лимит 5 часов в неделю, всё рутинное автоматизировано, модерация — одна метка |

## 11. Что уже готово в репозитории

- Формы заявок: новая вакансия, закрытие, спонсорство.
- Бот, который сразу проверяет заявку (обязательные поля, ссылка, дедлайн, дискриминационные требования) и показывает превью.
- Публикация по метке `approved`, включение Featured по метке `paid`, снятие с публикации по заявке «Закрыть».
- Автоматическое обновление README, JSON, RSS и сайта; ежедневная очистка; посты и дайджест в Telegram.
- Тесты логики (`tests/`) и проверка синхронизации в CI.

Что сделать владельцу, описано в [docs/setup.md](setup.md).
